# `docs/inflight/bugs/`

**Named for the defect, never for the date**:
`peer-index-build-page-not-found.md`, not `bug-2026-08-26.md`.

A file states, in this order: what the wrong behaviour is, the commit it
was verified at, the smallest reproduction, and what it costs — a refusal,
a slow answer, or a **quiet wrong answer**, which is the one that decides
priority. If the fix is known and merely unscheduled, say so and name the
work order that would carry it.
